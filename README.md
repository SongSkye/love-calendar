# 💕 恋爱日历 - 微信小程序

记录属于两个人的每一天：心情、日记、纪念日、照片。

## 功能特点

- 📅 **每日心情记录** — 两个人每天记录心情，月历展示，支持照片上传
- 📝 **日常日记** — 图文并茂的日记，时间线展示
- 💝 **纪念日管理** — 在一起天数、纪念日倒计时
- 📷 **照片记录** — 心情和日记都支持上传照片
- 🔗 **邀请码绑定** — 一人创建，另一人通过邀请码加入，数据互通共享

## 技术栈

- 微信小程序原生框架
- 微信云开发（云函数 + 云数据库 + 云存储）
- 完全免费，无需服务器

## 使用流程

### 对于使用者

1. **注册微信小程序**
   - 访问 https://mp.weixin.qq.com 注册个人小程序账号（免费）
   - 下载微信开发者工具

2. **开通云开发**
   - 在微信开发者工具中打开本项目
   - 点击"云开发"按钮，开通云开发环境
   - 获取你的云开发环境 ID

3. **配置项目**
   - 修改 `project.config.json` 中的 `appid` 为你的小程序 AppID
   - 修改 `miniprogram/app.js` 中的 `env` 为你的云开发环境 ID

4. **创建数据库集合**
   - 在云开发控制台 → 数据库 → 创建集合
   - 创建以下 5 个集合：`couples`、`users`、`moods`、`diaries`、`anniversaries`
   - 所有集合的权限设置为"仅创建者可读写"

5. **上传云函数**
   - 右键每个云函数目录 → 上传并部署

6. **预览测试**
   - 点击"预览"按钮，用手机扫码体验
   - 也可以用"真机调试"模式测试

7. **提交审核发布**
   - 填写小程序基本信息
   - 提交代码审核（工具类通常 1-2 天通过）
   - 审核通过后，所有人都能搜索到或扫码使用

## TabBar 图标

需要准备以下图标文件（40x40 像素 PNG），放在 `miniprogram/images/` 目录下：
- `calendar.png` / `calendar-active.png` — 日历图标
- `diary.png` / `diary-active.png` — 日记图标
- `heart.png` / `heart-active.png` — 纪念日图标
- `mine.png` / `mine-active.png` — 我的图标

可以从 iconfont.cn 或 flaticon.com 下载免费图标，或者暂时用纯色占位图替代。
